# GitHub Profile Finder

A small project I built while learning JavaScript and working with APIs.

You can enter a GitHub username and view their profile details without leaving the page.

### What it does
- Shows the user's profile picture, name, and bio
- Displays followers, following, and public repositories
- Links directly to their GitHub profile
- Handles invalid usernames and network errors
- Works on mobile and desktop screens

### Built with
- HTML
- CSS
- JavaScript
- GitHub REST API

### How to use it
1. Open the website in your browser.
2. Enter a GitHub username.
3. Click Search or press Enter to view the profile.

Built as a hands-on project to practise JavaScript, working with APIs, and updating the DOM.
